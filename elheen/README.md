# Elheen

The Elheen landing page, brand sheet and plan. This folder is separate from the
rizcoreach.ae site: nothing here is built or deployed by the main site.

| File | What it is |
|---|---|
| `index.html` | Landing page with the founding-business form |
| `thanks.html` | Page shown after the form is sent |
| `favicon.svg` | Icon: the saffron "now" dot |
| `BRAND.md` | Name, voice, logo, colours, type |
| `PLAN.md` | Stage-by-stage plan from 2026 to 2036 |

## Putting it live

1. Buy elheen.com.
2. In Netlify, add a new site from this repository and set **Base directory** to `elheen`.
3. Add elheen.com as the site's domain.

The form is a Netlify form called `elheen-founders`. Turn on email notifications
for it in Netlify so each request reaches you.

## Preview on your computer

Open `index.html` in a browser. No build step.
